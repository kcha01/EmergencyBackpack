# What does the web app do?

With this web app you can prepare your checklist for your backpack. Users can add items, delete them, sort by category, check their preparation status, check total cost, number of items and prepared items.

## Adding new item

With atributes: name, category, importance, quantity, price per unit
Categories to choose: food, tools, clothing, communication, others.
Importance to choose: necessary, important, less important.
![New_item](https://github.com/kcha01/EmergencyBackpack/blob/master/readme_images/1.PNG?raw=true)

After clicking the button, which adds new item, number of items and total cost changes.
